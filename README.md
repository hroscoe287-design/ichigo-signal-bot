# ICHIGO SIGNAL BOT

Separate signal-only trading dashboard inspired by VitalySvyatyuk's Pocket Option bot architecture.

## Features
- Ichigo/Bleach-inspired dashboard
- Live candle chart UI
- 1-second dashboard updates
- Pocket Option websocket adapter through environment variables
- EMA/trend, momentum and confluence scoring
- 75%+ signal glow tiers
- 95%+ Bankai visual state
- CALL / PUT / WAIT
- No automatic trade execution

The displayed percentage is a calculated setup-strength score, not a guaranteed win probability.

## Environment variables
- POCKET_WS_URL
- PO_AUTH_JSON
- ASSET
- TIMEFRAME

ALUCARD V4 is a separate project and is not modified by this repository.
